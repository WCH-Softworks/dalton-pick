# Contributing to DaltonPick

Thanks for your interest. DaltonPick is published as open source so that anyone can check what it does (no network access, no data collection), but it is developed by WCH Softworks alone.

## What's welcome

- **Bug reports and feedback** through [GitHub Issues](https://github.com/WCH-Softworks/dalton-pick/issues/new/choose). Wrong or confusing color names are especially useful: tell us the color (a hex code or a screenshot), the name DaltonPick showed, and the name you'd expect.
- **Security or privacy problems**, reported privately as described in [SECURITY.md](SECURITY.md).

## What isn't accepted

- **Pull requests.** Code, translation and palette changes are not accepted, and pull requests are closed without review. If you have an idea or a fix, open an issue describing it instead.
- **Requests for features that need the internet**, accounts, analytics or ads. DaltonPick stays offline by design.

## Forks

The code is under the [MIT license](LICENSE), so you're free to fork it. A fork must use its own name, icon and application ID, and must not be published as DaltonPick or as made by WCH Softworks.

## Issues are public

Don't post personal information, such as your email, phone number or anything identifying in screenshots. Issues that are off-topic, abusive or spam are closed and may be deleted.
