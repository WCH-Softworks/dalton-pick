# Security and privacy reports

DaltonPick has no internet permission and keeps nothing it reads from the screen or camera. If you find something that breaks that promise, or any other security problem, please report it **privately**:

GitHub → this repository → **Security** tab → **Report a vulnerability**.

Please don't open a public issue for these. You'll get a reply in the private report, and the fix will ship in a Google Play update.

Only the latest version on Google Play is supported.
